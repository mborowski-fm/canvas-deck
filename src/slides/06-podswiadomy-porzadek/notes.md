**Porządek działa, nawet gdy nikt go świadomie nie zauważa.**

Użytkownik wie, że coś jest nie tak, ale nie wie dlaczego. Naszą rolą jako designerów jest rozpracować te niewytłumaczalne rzeczy. Im więcej elementów na ekranie, tym trudniej zapanować nad harmonią.

- User czuje porządek, nawet gdy go nie widzi; i czuje burdel (np. 2 px przesunięcia)
- Więcej elementów = trudniej o harmonię
- Źródła porządku:
  - jedna skala spacingu (4 / 8 / 16 / 24 / 32)
  - powtarzalne promienie, grubości, wysokości komponentów
  - zagnieżdżone narożniki: wewnętrzny radius = zewnętrzny minus padding
  - Gestalt: bliskość, podobieństwo, ciągłość
